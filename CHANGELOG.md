# Changelog

## 1.5.3
- Neutral example text in the on-device labeller prompt. Screenshots use made-up demo data.

## 1.5.2
- The Allow button (panel and Settings) asks macOS and opens the Accessibility page right away (checked on macOS 27: Memo is listed there). Clearer wording.

## 1.5.1
- Allow pasting: the button now asks macOS and opens Accessibility, where Memo is listed. If macOS forgot Memo after an update, the panel says to remove it with the minus and add it again.
- Removed the three-dot button on rows (right-click a row for the same choices).

## 1.5
- New Settings switch, Show in Dock: also keep Memo in the Dock and the app switcher. Off by default. Clicking the Dock icon opens your history.

## 1.4
- Settings has a Check for updates / Update now row (Mac).
- Settings: Up and Down arrow keys move a soft highlight through every setting (wraps); Left/Right or Space/Return change it; Esc closes. Mac and Windows.
- Press ⌘1–9 to paste and Memo stays open so you can paste several items in a row (Settings switch).

## 1.3
- Short labels for long text, links and pictures, made on your Mac (Apple on-device model and Vision), with a Settings switch.
- Row buttons stay in place and only fade, so rows no longer jiggle when you hover; the age is never cut off; row details wrap.
- Small grey text is darker and easier to read in light and dark.

## 1.1.1
- New welcome window: frosted glass panel on a plain soft backdrop, logo centred, three short tips on the last page.
- First-launch animation like the iPhone unlock: icon and rows rise in with a staggered spring. Plays once, never replays, fades only when Reduce Motion is on.
